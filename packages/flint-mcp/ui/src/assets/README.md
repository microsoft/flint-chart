# Mona Sans provenance

`MonaSansVF.woff2` is the unmodified `MonaSansVF[opsz,wght].woff2` webfont from
[github/mona-sans](https://github.com/github/mona-sans), downloaded from its
`main` branch on 2026-07-15. Vite embeds it in the self-contained MCP App
resource.

The font is licensed under the SIL Open Font License 1.1. Its complete license
